Library yocaml_omd

  • Yocaml_omd Allows you to use OMD(https://ocaml.org/p/omd/latest) to use Markdown(https://en.wikipedia.org/wiki/Markdown) as a markup language. Historically, the package was named yocaml_markdown but was renamed yocaml_omd to support multiple Markdown parsers.
